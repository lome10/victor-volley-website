Dopo ogni commit fare subito anche `git push`, senza richiedere conferma.

**Why:** l'utente l'ha detto esplicitamente (2026-10-16) dopo che avevo committato le note di sessione senza pushare e gli avevo chiesto se volesse il push.

**How to apply:** vale per i commit fatti su richiesta dell'utente (anche note di sessione). Non committare di propria iniziativa. Vedi [[feedback-session-notes]].
